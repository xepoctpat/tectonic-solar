## Editor chrome (the non-Copilot part)

These are the changelog items that apply whether or not Copilot is open.

### Layout density (Experimental) — new choice, not a new tab height

**Settings:** `workbench.experimental.modernUI` (gate) then `window.density.layout` (`default` | `compact`)

Also in **Customize Layout** (title-bar layout button) → **Layout Density**.

| Value | What it does |
|---|---|
| **Default** | Same as current Modern UI: ~4px gap between sidebar / editor / panel “cards”, normal inner padding |
| **Compact** | Those inter-panel gaps go to **0**; inner panel padding shrinks. More pixels for the file + terminal. Outer window chrome still keeps a 4px perimeter |

This is **not** the same knob as the two density settings already on this machine:

| Existing user setting | Current value | What it controls |
|---|---|---|
| `workbench.activityBar.compact` | `true` | Activity Bar **icon strip** size (classic compact icons) |
| `window.density.editorTabHeight` | `"default"` | Editor **tab bar** height (you kept default, not compact tabs) |
| `window.density.layout` *(1.136)* | **unset** | Gaps **between** workbench parts once Modern UI is on |

You already compact the Activity Bar, but you also spend vertical space on **pinned tabs on a separate row**, a **large** title scrollbar, tab indexes, and always-visible editor actions. Compact *layout* density only collapses panel gutters; it will not squash those tab-row choices. It also will not do anything until Modern UI is on (product A/B or the experimental setting).

**Do not put these keys in this repo.** Try Compact from Customize Layout if the extra card gaps bother you; set `window.density.layout` back to `default` (or disable Modern UI) if the panes feel glued together.

### Word wrapping vs injected text — automatic

No setting. Wrapped lines now reserve width for color decorators, inlay-hint spacing, inline progress, and breakpoint placeholders, so the last token is not cropped at the viewport edge.

This machine: global `editor.wordWrap` is **off**, inlay hints **off**. The wrap fix mainly shows up in the language overrides that wrap (`json` / `jsonc` / `markdown`) and anywhere a CSS color decorator sits on a wrapped line. JS in this tree stays unwrapped unless you turn wrap on.

Quiet related fixes in the same train (no action): hover can scroll long content again; explorer memory leak; out-of-bounds wrap selection; custom line heights rounded.

### Integrated browser + terminal

- Simple Browser: right-click a misspelled word → suggestions; **Add to Dictionary** if that browser session has persistent storage. Still do not pin `*.html` as the default editor.
- Extension-run terminal commands no longer add a ~5s wait when shell integration is already ready (JS debugger start is the named case). `npm run launch` / Playwright from the integrated terminal benefit if you hit that path.
